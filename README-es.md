# dsh-ar-collection

> **Repositorio oficial. El único repositorio oficial de este paquete, mantenido por PerryLink. Apache-2.0.**

</div>

Convierte un libro auxiliar de cuentas por cobrar en CSV en un plan de cobro por cliente con escalones de 7/15/30 días, borradores de cartas de cobro en chino y una lista de cobro CSV. Todo se ejecuta localmente: las cartas nunca se envían, no hay red ni carga de datos.

## Documentación completa

La documentación completa (instalación, permisos, ejemplos, reglas de escalones y solución de problemas) está en [README.md](README.md) y [README-zh.md](README-zh.md).
